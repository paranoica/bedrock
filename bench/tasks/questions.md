# Inventory questions

Answer each from the code, with the file and line that shows it.

1. What is the default chunk size, and the default overlap?
2. Which files does `load` read, and which does it skip?
3. How is the index stored on disk, and is the write atomic?
4. What does `search` return for an empty query?
5. Where is the BM25 inverse document frequency computed, and what counts as a document?
6. How are words normalised in the index, and how in the query?
7. What does `highlight` do with HTML in the text?
8. What happens to the last words of a document whose word count is not a multiple of the
   chunk size?

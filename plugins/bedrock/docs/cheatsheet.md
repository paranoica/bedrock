## Слова

| Говоришь | Скилл |
|---|---|
| «надо сделать …», «начинаем день» | day |
| «падает», «не работает», «почему» | debug |
| «что дальше?», «можно чиллить?» | next |
| «быстро скажи …», «как у нас работает …» | ask |
| «проверь», «ревью» | review |
| «запиши решение», «обнови заметку» | kb |
| «передай смену», «продолжаем» | handoff |
| «разбери созвон» | call |
| «сделай отчёт» | doc |
| «очеловечь», «ответь ему» | humanize |
| «разбери баги» | triage |
| «сломай это», «поищи баги» | hunt |
| «прогони e2e» | e2e |
| «ретро» | retro |
| «автономно до утра» | night |

## Только руками

| Команда | Что делает |
|---|---|
| `/bedrock:start` | подключить или начать проект |
| `/bedrock:arch` | архитектурное ревью |
| `/bedrock:allow push` | разрешить одно действие |
| `/bedrock:unleash до утра` | разрешить всё до срока |
| `/bedrock:revoke` | забрать все разрешения |

## Команды в терминале

| Команда | Что показывает |
|---|---|
| `bedrock doctor` | чего не хватает машине |
| `bedrock project check` | ошибки в настройках проекта |
| `bedrock backlog list` | задачи проекта |
| `bedrock minutes <блок>` | минуты по блоку |
| `bedrock kb validate` | ошибки в базе знаний |
| `bedrock kb drift` | заметки, отставшие от кода |
| `bedrock retro` | неделя в цифрах |
| `bedrock backup` | шифрованный снимок базы, без push |

## Риск и приоритет

* R1: без логики. R2: обычный код. R3: опасное, новое, критическая зона.
* P0: горит сейчас. P1: на этой неделе. P2: обычная очередь. P3: когда-нибудь.

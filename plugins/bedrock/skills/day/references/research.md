# Research (D034)

- Library or API usage: context7 and the official documentation, in parallel. They agree:
  proceed. They conflict: the official documentation wins and the conflict is noted.
- A quick fact: one web search in the session.
- Where things are in code: search, LSP, `bedrock map defs <symbol>` (a fresh map only).
- Comparing approaches across many sources: an `analyst` agent, report to a file.
- Decisions rest only on sources actually opened and read; the report marks each source
  opened or found-only. Version-sensitive behaviour is checked against current docs.
- Queries carry nothing internal: no client names, code or product words.
- Mandatory for R3; for R2 with an unfamiliar library; never for R1.
